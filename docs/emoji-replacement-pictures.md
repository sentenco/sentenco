# Pictures that replace the emoji (A1 Kids)

All emoji were removed from the 72 A1 Kids lessons. Where an emoji carried meaning (counting objects, feeling
faces, cake, candles) the lesson now loads a picture. A picture that is not added yet shows a dashed circle.

Save each file with the exact name below. Nothing else needs to change.

Style for every prompt: kawaii chibi cartoon, thin dark-brown outlines, soft flat shading, plain white background,
no text, no watermark, square 1:1, one item centered, fills most of the frame.
