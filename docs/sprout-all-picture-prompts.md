# Sprout A1 (Adults) picture prompts

Every picture the rebuilt Sprout A1 lessons need (Units 1 to 12). Style: mature flat vector illustration with realistic adult proportions (not chibi). Save each as `.jpeg` at the path shown, under `public/curriculum/sprout/`. A missing picture shows a dashed placeholder in the lesson, so pictures can arrive in any order, in any batch. Each prompt already includes the style prefix.

Notes: use the same adult characters across a unit when a picture shows a named cast member. Counts matter where stated (for example, exactly six apples).
