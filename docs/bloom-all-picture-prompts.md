# Bloom A2 (Adults) picture prompts

Every new picture the rebuilt Bloom A2 lessons need (Units 1 to 12). Style: mature flat vector illustration with realistic adult proportions (not chibi), same look as Sprout. Save each as `.jpeg` at the path shown, under `public/curriculum/bloom/`. A missing picture shows a dashed placeholder in the lesson, so pictures can be added at any time. Bloom also reuses a few Sprout pictures (travel, health, work, rooms) that are listed in the Sprout prompts file.

Notes: use the same adult characters across a unit when a picture shows a named cast member. Cast portraits are one person each, bust portrait facing forward.
