# Ablaze A2 (Teens) picture prompts, all units (1 to 12)

Every NEW picture the rebuilt Ablaze A2 lessons need (Units 1 to 12). Save each as `.jpeg` at the path shown, under `public/curriculum/ignite/chibi/`. A missing picture shows a dashed placeholder in the lesson, so they can arrive in any order, in any batch. Each prompt already includes the style prefix.

Ablaze also reuses many pictures from the Ignite A1 list (clothes, free time, hobbies, tech, food, meals, school day, weather, routine). Those prompts live in `docs/ignite-all-picture-prompts.md`, so generate that list too.

Cast portraits are older teens (13 to 17) and each unit has its own 4 friends. Style sets: people and scenes use the chibi style; objects and icons use the flat kawaii icon style.
